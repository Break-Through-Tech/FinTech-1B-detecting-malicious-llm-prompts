# Presentation artifact package

The final package should contain only reviewable, source-linked artifacts:

- a concise results report naming the selected model and operating point;
- legible figures generated from the frozen evaluation run;
- a limitations and responsible-use summary covering false negatives, bias, leakage, and deployment boundaries; and
- [`docs/final-delivery-checklist.md`](final-delivery-checklist.md) with the commands and validation receipt.

Each report or figure must identify the dataset revision, split, seed, model configuration, threshold, and generating command. Raw prompts, raw dataset files, credentials, and accidental notebook outputs must not be packaged. Until the final evaluation and detector demo exist, this file is a packaging contract rather than a claim that those artifacts are available.
